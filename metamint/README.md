# MetaMint

أداة محلية لإضافة الكلمات المفتاحية إلى بيانات الصور بدون رفعها إلى أي خادم وبدون إعادة ضغط البكسلات.

## التشغيل

على Windows اضغط مرتين على `Open MetaMint.cmd`. ويمكنك أيضاً فتح `index.html` مباشرة بمتصفح حديث مثل Chrome أو Edge. لا يحتاج البرنامج إلى تثبيت أو اتصال بالإنترنت بعد فتحه.

## الصيغ المدعومة

- JPG / JPEG: تكتب الكلمات داخل IPTC Keywords وXMP `dc:subject`.
- PNG: تكتب XMP وحقول iTXt قابلة للقراءة.

تُحفظ الصورة الأصلية كما هي، ويخرج البرنامج نسخة جديدة ينتهي اسمها بـ `-tagged`.

## ملاحظة Etsy

البيانات المضمنة مفيدة لتنظيم الملفات وحقوق النشر. ظهور المنتج داخل Etsy يعتمد أساساً على عنوان الـlisting، و13 tags، والوصف، والتصنيف، والخصائص داخل Etsy نفسه.
